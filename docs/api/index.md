# API Reference

This is a focused, hand-maintained reference for the host-facing API. It is checked against the current source; it is not an exhaustive generated member listing. XML documentation shipped with the assembly supplies additional IDE help.

| Area | Entry points |
| --- | --- |

| [Configuration](/api/configuration) | `FreeRdpConfiguration` and nested configuration objects. |
| [Diagnostics](/api/diagnostics) | `FreeRdpDiagnosticsOptions`, `FreeRdpDiagnosticEventArgs`, and per-launch capture. |
